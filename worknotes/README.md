# 工作笔记 · Kivy Android 版

一个给自己用的**安卓小笔记本**：把日常工作中的操作步骤和维修办法按「板块」分类记下来，
遇到问题时按**提示词/关键字**一搜就能找到解决办法。

界面刻意做得简单：左边板块列表，中间笔记列表，上面一个搜索框。

---

## 一、功能

### 1. 多板块笔记
- **默认三个板块**：`医院HIS系统操作`、`打印机维修`、`总结笔记`
- **可新建板块**：点左下角「＋ 新建板块」，自己起名（比如「医保接口」「呼叫器」）
- **可重命名板块**：长按左侧板块按钮即可改名
- **可删除板块**：选中某板块后点「删除板块」；该板块里的笔记会移到「未分类」保留，不会丢内容
- 左侧按钮显示每个板块的笔记数量

### 2. 一条笔记 = 一个问题的解决办法
每条笔记包含：
| 字段 | 说明 |
|------|------|
| 提示词（标题） | 问题现象，如「HIS登录提示密码错误」 |
| 标签 | 可选，空格分隔，如 `his 登录 报错` |
| 正文 | 操作步骤 / 维修办法，可多行 |
| 置顶 | 置顶的笔记永远排最前 |
| 板块 | 归属哪个板块 |

### 3. 搜索（核心用途）
- 顶部搜索框输入关键字，**标题优先匹配**，其次是标签和正文
- 「全局」= 跨所有板块搜索；「本板块」= 只在当前板块搜
- 搜索结果高亮选中行，底部显示命中条数

### 4. 其他
- **自动保存**：每次保存立即写盘，重启不丢
- **导出备份**：一键导出 JSON 到手机存储，可换机迁移
- **中文字体**：已把 `simhei.ttf`（黑体）打包进 APK，安卓上中文正常显示

## 三、怎么在手机上运行（拿到 APK）

本机没有 Android SDK / Java，也上不了外网，所以**无法在你这台电脑上直接编译**。
最省事的办法是让 GitHub 的服务器替你编译：

### 步骤 1：把项目上传到 GitHub
1. 注册/登录 [github.com](https://github.com)
2. 点右上角 **＋ → New repository**，名字随意（比如 `worknotes`），选 **Private**（私有，别人看不到）
3. 按页面提示把 `worknotes` 文件夹、`.github` 文件夹一起推到仓库

   > 也可以直接在网页上点 **Add file → Upload files**，把整个 `worknotes` 文件夹拖上去
   > （注意 `.github/workflows/build-apk.yml` 也要一起上传，否则不会自动构建）

### 步骤 2：触发云端构建
- 上传完成后，进入仓库的 **Actions** 标签页
- 左侧看到 **Build APK**，点进去 → 右侧 **Run workflow** → 再次确认
- 等待约 **20～50 分钟**（GitHub 免费额度足够）

### 步骤 3：下载 APK
- 构建完成后（绿色 ✓），页面下方 **Artifacts** 区有 `worknotes-apk`
- 下载、解压，得到 `*.apk`，传到手机安装即可
- 首次安装需允许「安装未知来源应用」

> 构建失败时可在同一页面下载 `build-log` 排错。

## 六、常见问题

**Q：安装后中文是方块？**
A：已把 `simhei.ttf` 打包进 APK（见 `buildozer.spec` 的 `android.add_fonts`）。若仍异常，
把别的中文字体（如 `NotoSansCJKsc-Regular.otf`）放进 `fonts/` 目录并修改该行。

**Q：想改应用名字/图标？**
A：名字在 `buildozer.spec` 的 `title = 工作笔记`；图标准备一张 192×192 png，
取消 spec 中 `icon.filename` 的注释并指向你的图片。

**Q：怎么加更多默认板块？**
A：改 `main.py` 顶部的 `DEFAULT_BOARDS` 列表。注意这只在**首次运行**生效，
之后以存储文件里的 `boards` 为准。
